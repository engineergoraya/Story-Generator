# 🌟 AI Kids’ Story Generator Website  

An interactive **web application** that generates fun, creative, and personalized stories for children using **Generative AI**.  
The platform offers both **reading** and **listening** options with integrated **Text-to-Speech (TTS)**, making storytelling engaging and accessible.  

---

## 🚀 Features  
- **AI Story Generation** – Creates unique stories in real-time using prompt engineering.  
- **Customizable Options** – Choose characters, settings, or themes to personalize the experience.  
- **Read or Listen** – Integrated TTS provides a storytelling vibe with a clear, friendly voice.  
- **Kid-Friendly UI** – Simple, colorful interface for ease of use.  
- **Web-Based** – Runs directly in the browser, no installation required.  

---

## 🛠️ Tech Stack  
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Flask (Python) / Replit Hosting  
- **AI Tools**: Generative AI APIs for text creation  
- **Voice**: Web Speech API / Retell AI (for TTS integration)  

---

## 📖 How to Use  
1. Open the website in your browser.  
2. Enter a character, setting, or theme.  
3. Click **Generate Story**.  
4. Choose to **read** the story or **listen** to it with TTS.
